# Grille du tuteur IA — pilote prostate

Le tuteur évalue cinq axes, chacun sur deux points :

1. justesse de la conclusion ;
2. détection des données manquantes ;
3. stratification du risque ;
4. raisonnement d'oncologie médicale ;
5. raisonnement local et multidisciplinaire.

Erreurs critiques de la première boucle :

- conclure qu'un PSMA-PET négatif exclut toute maladie microscopique ;
- omettre l'ADT par principe uniquement parce que le PSMA-PET est négatif ;
- présenter l'ADT seule comme traitement curatif standard de ce dossier M0 ;
- prescrire une stratégie définitive sans considérer le terrain ni les préférences.

La remédiation doit cibler une seule lacune prioritaire avant un re-test de transfert.
